# مرجع التنفيذ — المجرة وبنون

اقرأ الملفات الحية عند البناء. هذا الملف يذكّر بالثوابت لا أن يُنسخ أعمى.

## المكدس

- Next.js 16 App Router، React 19، Tailwind 4، shadcn (radix-nova)
- `lang="ar"` `dir="rtl"`، خط `app/fonts/DroidArabicKufi-*.ttf`
- `qrcode.react` لواتساب المبيعات وواتساب المطوّر
- `sonner`، `recharts`، تقييم يُحفظ في `localStorage` فقط

انسخ من المرجع: `components/ui/*`، `app-shell`، شريط علوي، تذييل، `HonestyNote`، `HumanInTheLoop`، `SalesCallBar` (أو ما يعادله).

## تواصل المنصة (`lib/config.ts`)

أولوية الرقم: مستخدم → إكسل إن وُجد → صفحة Contact في الموقع.
البريد: مستخدم → عنوان ظاهر على الموقع → لا تخترع صندوقاً.
الموقع الجغرافي وساعات الدوام: كما نُشر، وإلا «غير منشور».

GitHub: حساب `kazoya`، مستودع عام باسم المشروع.
Vercel: فريق `muqasa`، `create_git_project` بعد الدفع إلى `main`.

## ماذا يتغيّر في كل مصنع

| يتغيّر | لا يتغيّر |
|--------|-----------|
| الألوان من الشعار | صدق المصدر أو الاعتذار |
| الكتالوج من الموقع | شارة البيانات التجريبية |
| المحرّك التفاعلي (ري / مسابقة / …) | اعتماد بشري قبل التنفيذ |
| رسائل المبيعات وجمهور الإغلاق | «ليس نظاماً رسمياً» |
| صفحة الشركة الأم إن وُجدت | QR المطوّر الافتراضي |

## محرّك تفاعلي

اختر **واحداً** يغلق الصفقة:

- حقل/ري → اقتراح مدة لا يفتح صماماً
- مدارس/تجزئة → مسابقة نقاط وجائزة لا تُعلن وحدها
- B2B طلبات → التقاط واتساب ثم طابور تسعير
- جودة/غذاء → ادعاء المكوّن معلّق حتى ملف مختبر
