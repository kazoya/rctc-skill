# Delivery checklist

## Before coding

- [ ] Skill files read (`SKILL.md` + needed satellites)
- [ ] Path routed (Factories / personal / not Belt-muqasa-core)
- [ ] Intake minimum met or assumptions stated
- [ ] Source site inspected (or bio ledger complete)

## Build

- [ ] Brand colors from real logo/site
- [ ] Config contacts verified — nothing invented
- [ ] One interactive engine + human-in-the-loop
- [ ] WhatsApp QR ≤ 2 placements; `rel=noopener noreferrer`
- [ ] Independent-concept footer
- [ ] `npm run build` green

## Ship

- [ ] Commit without secrets
- [ ] GitHub repo pushed
- [ ] Vercel READY (or explicitly deferred by user)
- [ ] Production URL opens

## Hand-off

- [ ] Folder path
- [ ] GitHub URL
- [ ] Live URL
- [ ] Unknowns list
- [ ] Mention pairing value of **safe-forward-execution** if user asks how to reduce babysitting next time
