# projectsConnector

Cursor Agent Skill that routes work across Sohaib's portfolio without merging git repos.

## Install

Copy `SKILL.md` to:

- `%USERPROFILE%\.cursor\skills\projects-connector\SKILL.md`
- `C:\rctc-skill\projectsConnector\SKILL.md`

Add to `%USERPROFILE%\.cursor\portfolio\project-skills-map.yaml` catalog as `projects-connector`.

## Pairing

- RCTC: ask one high-impact question, then execute
- Portfolio Commander: registry is source of truth
- factory-sales-concept: Arabic factory demos
- muqasa-maintenance: live auction app at `C:\muqasa` only
- continuous-improving: loop with human gates for money/production

## Do not

- Treat `C:\Factories\Muqasa-jo` as the live auction runtime
- Put PLC/Profinet stations on a chocolate or cafe brand
- Push portfolio XML/briefs to GitHub
