# Focus Council — ركّز الإجابة قبل أن ترفع الصوت

**عدة زوايا خبيرة، خلاف منظم، لجنة تقييم محايدة، ثم إجابة واحدة مركزة.**

هذه المهارة تحول سؤالاً صعباً من إجابة أحادية المسار إلى عملية اختيار قابلة للمراجعة:

```text
FRAME
  ↓
SIMULATED EXPERT PERSPECTIVES
  ↓
INDEPENDENT PROPOSALS
  ↓
CROSS-CRITIQUE
  ↓
SHORTLIST
  ↓
NEUTRAL JURY
  ↓
SYNTHESIS
```

## مثال سريع

> “أريد أفضل طريقة لخفض تكلفة TTS العربي مع الحفاظ على الجودة.”

بدلاً من جعل “خبير واحد” يختار مباشرة، يمكن للمجلس تمثيل منظور مهندس Arabic NLP،
ومهندس Speech/TTS، ومهندس FinOps/API، ومطور منتج، ومراجع وصولية؛ ثم مقارنة الحلول
وتقييمها وفق تكلفة قابلة للقياس وجودة وLock-in وتشغيل.

**مهم:** الشخصيات زوايا تحليل محاكاة وليست أشخاصاً حقيقيين أو زبائن حقيقيين.

## الاستخدام

اطلب مثلاً:

```text
Use /focus-council in STANDARD mode.
Problem: <your problem>
Candidates: 3
Jurors: 3
Optimize for: quality, cost, time-to-value.
```

أو بالعربية:

```text
استخدم مهارة Focus Council.
شكّل 5 وجهات نظر خبيرة مرتبطة مباشرة بالمشكلة،
استخرج أفضل 3 حلول، ثم اجعل 3 مقيّمين محايدين يقيمونها،
وأعطني الحل المركّز والبديل الثاني ومتى يصبح أفضل.
```
