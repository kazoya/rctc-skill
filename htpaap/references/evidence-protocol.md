# Engineering lesson evidence protocol

Use one receipt per extracted lesson.

## Receipt

- Source repository and URL:
- Revision/tag/commit:
- Access date:
- Learning target:
- Primary evidence paths:
- Observed fact:
- Upstream author's stated claim:
- Inference (if any):
- Competing explanation:
- Local transfer candidate:
- Authorization and affected repository:
- Before evidence:
- Change or experiment:
- Verification command/result:
- After evidence:
- Limits and unresolved questions:
- Reuse classification: source-specific / broadly reusable / uncertain

## Evidence grades

| Grade | Meaning |
|---|---|
| A | code/test plus reproducible result and pinned revision |
| B | primary documentation plus corroborating implementation or issue |
| C | primary documentation only |
| D | secondary summary or inference; do not operationalize without more work |

Never upgrade a grade because an AI explanation sounds convincing.
