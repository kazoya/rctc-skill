# 🔬 Focused3 Agentic Phases

> **THINK → EXECUTE → PROVE**

مهارة تمنع التقدم الوهمي بفصل العمل إلى ثلاث مراحل مترابطة: فهم المهمة وعقدها، تنفيذها فعلياً، ثم إثبات النتيجة بالدليل المناسب.

## لماذا تحتاجها؟

لأن وجود كود لا يعني أن الميزة تعمل، ونجاح البناء لا يعني أن رحلة المستخدم نجحت.

```text
DONE = IMPLEMENTATION × TEST × VERIFICATION × EVIDENCE
```

إذا كان أي عامل صفراً، فالإنجاز غير مكتمل.

## أفضل استخدام

- مشاريع البرمجيات عالية الدقة.
- تغييرات تحتاج Quality Gates واضحة.
- مسابقات وتجارب تحتاج نتائج قابلة لإعادة الإنتاج.
- مراجعة التسليم قبل قول «تم».

استخدمها مع [Safe Forward Execution](../safe-forward-execution/): الأولى تحافظ على الزخم، وهذه ترفع معيار الإثبات.
