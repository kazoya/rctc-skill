# القيود — غير قابلة للتفاوض

هذه قرارات المالك لا تفضيلات. أي اقتراح يخالفها يُرفض مهما كان مقنعاً.

## الصدق
- لا رقم سوق أو إيراد أو مستخدمين أو شركاء أو شهادات غير موجودة في الحزمة.
- ما هو موسوم «محاكاة» أو «مخطط» أو «مدخل من المالك» يبقى كذلك؛ لا يُحوَّل إلى «مبني» أو «حيّ».
- لا تُملأ حقول `[OWNER INPUT]`. أي رقم جديد يحمل مصدراً مؤرخاً أو وسم افتراض.
- إذا ادّعيت أن شيئاً موجود في الكود، أشر إلى الملف والسطر داخل `source/`.
- إن وُجد `data/` بسجل ادعاءات أو أرقام مالك: لا تغيّر ادعاءً ولا رقماً؛ اقترح في التقرير فقط.

## الكود
- لا تغيّر القواعد المحمية (محركات مالية، سياسات أمان، نصوص إيقاف) إلا بتقرير يسمّي الخطأ ولا يطبّقه صامتاً.
- لا تبعيات جديدة ثقيلة؛ لا خطوط أو سكربتات خارجية غير الموجودة.
- الهوية البصرية والرموز في ملف الأنماط تبقى؛ لا إعادة تصميم.
- الوصول: H1 واحد لكل صفحة، تباين AA في الوضعين، لا تمرير أفقي على 390px، كل حركة تحترم `prefers-reduced-motion`.
- بوابة القبول تبقى خضراء: `npm run verify` (lint + typecheck + build + tests). إن لم تستطع تشغيل المتصفح فقل ذلك ولا تدّعِ نجاح E2E.

## النشر
- لا نشر ولا تعديل على GitHub/Vercel/أسرار/متغيرات بيئة. التسليم ZIP + تقرير؛ الدمج قرار المالك.

## اللغة
- العربية الفصحى المبسّطة أولاً؛ الإنجليزية حيث توجد أصلاً فقط.
