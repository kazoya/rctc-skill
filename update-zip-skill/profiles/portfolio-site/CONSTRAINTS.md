# قيود المحفظة — غير قابلة للتفاوض

هذه قرارات المالك لا تفضيلات. أي توصية تخالفها تُرفض مهما كانت مقنعة.

## الصدق قبل كل شيء
- **لا تغيير لأي رقم أو عميل أو تاريخ أو شهادة أو ادعاء في `data/`** ولا في `OUT/`. المحتوى قرار المالك؛ اقترح في `REPORT.md` ولا تطبّق.
- السنوات الأولى (قبل 2002) بلا تواريخ عمدًا. لا سنوات خبرة لأداة بعينها.
- خبرات DOS والوسائط واستعادة البيانات **تأسيسية**، لا مهارات 2026. لا ادعاء شهادة BSCP (جاهز للامتحان فقط). أكاديمية APCA «مُظهِر مقترح متوافق مع أهداف GIZ»، ليست اعتمادًا.
- الوكلاء أداة تحت قيود مكتوبة؛ صهيب هو الفاعل في كل صياغة. لا «Claude بنى» ولا «Cursor نفّذ».
- الأرقام العامة تأتي من تحقق مؤرَّخ (HTTP، Lighthouse، Playwright)، لا من تصدير قديم.

## الهوية
- كريمي/أخضر هادئ، بطاقات بزوايا 1.5rem، Droid Arabic Kufi + Geist Mono، وضع داكن عبر `data-theme`.
- **لا إعادة تصميم.** لا gradients صاخبة، لا زجاجية، لا نيون، لا طرفية مزيفة، لا روبوتات، لا شعارات عملاء مخترعة.
- العربية RTL أولًا؛ الإنجليزية LTR تحت `/en` بترويسة وتذييل ولوحة أوامر إنجليزية.

## بوابات القبول (كلها، لا بعضها)
- `npm run verify` أخضر: lint 0 · typecheck · verify:assets · build · Playwright (بما فيه axe: صفر serious/critical في الوضعين).
- Lighthouse جوال ≥ 90 على `/` و`/journal` و`/en` و`/en/journal`، CLS = 0، لا تراجع > 3 نقاط دون تفسير مقبول.
- H1 واحد لكل صفحة، canonical ذاتي، hreflang على الجذرين، لا تمرير أفقي على 390px، لوحة الأوامر بالكيبورد.
- كل حركة تحترم `prefers-reduced-motion`؛ المؤثرات كلها خلف `NEXT_PUBLIC_EFFECTS=off`.
- لا مكتبة جديدة قبل إثبات أن API المتصفح لا يكفي. الميزانية: ≤ 8 KB gzip لأي طبقة تفاعل.

## التشغيل
- لا أسرار، لا `.env`، لا تعديل إعدادات Vercel أو GitHub، لا نشر. التسليم فرع/ZIP + تقرير.
- ملفات الكود تُسلَّم كاملة تحت `IMPROVE/changed-files/<المسار نفسه في المستودع>`، لا مقاطع ولا diff نصّي.
- `REPORT.md` بالحقول: Baseline observed · Changed files · Behavior evidence · Quality gates · Performance budget · Safe to say now · Do not promise yet · Rollback.
