# قيود PtreeLink — غير قابلة للتفاوض

هذه قرارات المالك والمعمارية لا تفضيلات. أي توصية تخالفها تُرفض مهما كانت مقنعة.
القرارات الكاملة (15 قراراً) مُلحقة أدناه من `docs/blueprint/DECISIONS.md` في المستودع.

## المنتج
- منصة مستقلة أولاً؛ Embed/Plugin/SDK قنوات توزيع لاحقة لا نواة. لا اعتماد على Linktree.
- الذكاء الاصطناعي يقترح مسودات فقط؛ الإنسان ينشر ويوافق على أي فعل خارجي. المنتج الأساسي يعمل مع تعطيل كل مزودي AI.
- كل معلومة مستوردة تحمل `source / confidence / extractedAt / needsReview`، ولا نشر تلقائي لأي منها.
- لا تخفيف خفي لشروط البحث، ولا مطابقات مختلقة. سلم النتائج الصفرية يقترح شرطاً واحداً ويعرضه مشطوباً مع شارة ويسجّل revision.
- المطابقة مفسّرة (matched / missing / unknown / evidence / weights) وليست قرار توظيف. السمات الحساسة (العمر، الجنس، الدين، الإعاقة، الحالة العائلية) محظورة في المطابقة الوظيفية افتراضياً.
- لا scraping خلف تسجيل دخول ولا تجاوز CAPTCHA؛ robots.txt يُحترم.

## المعمارية
- Modular monolith. schema واحد في `src/db/schema` (Drizzle) وmigrations مولّدة؛ SQL يدوي في migrations مخصصة فقط.
- RLS deny-by-default على كل جدول خاص. الـprojection العامة (`published_profiles`, `search_documents`) تُكتب عبر `publish_entity()` فقط؛ لا تقرأ الواجهة جداول خاصة ثم تحذف حقولاً.
- الواجهة لا تستورد Drizzle مباشرة؛ الطريق: Server Action (Zod) → `modules/*/service.ts` → `withRls()`.
- عربية RTL أولاً وإنجليزية LTR؛ لا نصوص صلبة في المكوّنات (messages/*.json)؛ خصائص منطقية لا left/right.
- أسماء النماذج والمزودين إعدادات لا منطق عمل.

## بوابات القبول (كلها لا بعضها)
- `pnpm typecheck` 0 أخطاء · `pnpm lint` 0 · `pnpm test` أخضر · `pnpm build` ناجح · `pnpm test:e2e` أخضر على desktop و360px.
- اختبار RLS سلبي لكل جدول جديد (مستخدم آخر لا يقرأ/يعدّل بمعرفة الـid).
- لا `any` غير مبرر، لا stubs تُقدَّم كمنجز، لا migration غير مطبقة تُوصف بأنها منجزة.
- الحركة تحترم `prefers-reduced-motion`؛ touch targets ≥ 44px؛ skip link وheadings سليمة.

## التشغيل
- لا أسرار، لا `.env`، لا تعديل إعدادات Vercel/Supabase، لا نشر، لا فوترة. التسليم ملفات كاملة + تقرير.
- التغييرات على الكود تُسلَّم كاملة تحت `IMPROVE/changed-files/<المسار في المستودع>` وتُطبَّق على فرع مراجعة فقط بعد بوابات خضراء؛ الدمج قرار المالك.
- لا مكتبة جديدة قبل إثبات أن ما هو قائم لا يكفي.
- احتفظ بالعمل القائم؛ اطلب إذناً لأي حذف أو migration إنتاجية أو إرسال خارجي.
