# 🛡️ Safe Forward Execution

> **الخطة محطة داخلية، وليست نهاية المهمة.**

هل سئمت من وكيل يكتب خطة ممتازة ثم يتوقف؟ هذه المهارة تدفعه من التخطيط إلى **تنفيذ قابل للتحقق** ما دامت الخطوات داخل نطاق طلبك، آمنة، وقابلة للتراجع.

## ماذا تفعل؟

- تميز بين طلب التنفيذ وطلب التخطيط أو التشخيص فقط.
- تواصل العمل دون أسئلة غير ضرورية.
- تحافظ على تغييرات المستخدم وحدود الصلاحية.
- تكمل الأعمال الآمنة حتى لو تعطل مسار جانبي.
- تطلب المستخدم عند النشر، الدفع، الأسرار، القرارات الجوهرية أو المخاطر الحقيقية.
- لا تعتبر العمل منجزاً دون دليل يناسب الادعاء.
