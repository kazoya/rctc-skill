# Coffee Pass — شرف داعمي القهوة (Buy Me a Coffee)

اللهم ارزقني وارزق مني.

من دفع ثمن قهوة عبر [Buy Me a Coffee](https://buymeacoffee.com/Asrawi612) يستحق **شكراً حقيقياً** ووصولاً مبكّراً ألطف لمرحلة 2 (Skill Factory / Packages / Dev Agora) — بدون إجبار وبدون أرقام وهمية.

## الأمان أولاً (مهم جداً)
- **لا تُقرض رقم بطاقتك لأحد** ولا تطلب ذلك من أحد. مشاركة بيانات الدفع خطر واحتيال محتمل.
- إن أحببت مساعدة زميل يتعلم ولا يملك ثمن القهوة: **اشترِ له قهوة كهدية** من صفحة BMC، أو دُلّه على المسار المجاني الكامل عبر GitHub (ستار / Issue / Discussion).
- PayPal البديل للمالك: `innervision2016@gmail.com`

## كيف تثبت الدعم (نص المرور)
بعد الدفع احتفظ بواحد مما يلي (لا تلصق أسرار بطاقة):
1. **رقم إيصال / Receipt / Order ID** من رسالة Buy Me a Coffee، أو
2. لقطة شاشة للإيصال (احذف أي بيانات بطاقة)، أو
3. رابط صفحة الشكر إن وُجد في بريد التأكيد

ثم افتح Issue بعنوان:
`[Coffee Pass] <اسمك أو لقبك>`

استخدم القالب: `.github/ISSUE_TEMPLATE/coffee_pass.yml`.

المالك يراجع يدوياً ويمنح وسم `coffee-supporter` و/أو يضيف سطراً في `packages/coffee-pass/SUPPORTERS.md`.

## المستويات (درجات أنيقة)

| المستوى | الدليل | الشرف |
|---|---|---|
| **L0 — Explorer** | ستار أو تعليق مفيد على GitHub | شكر + دعوة لباقة `beginner-coding-path` |
| **L1 — Coffee Friend** | إيصال BMC / PayPal مؤكد | وصول مبكّر لمسودات Phase 2 + شكر في Discussions عند التفعيل |
| **L2 — Table Host** | قهوة + وصفة/مثال مفيد | ذكر اختياري في `SUPPORTERS.md` + أولوية مراجعة Skill Proposal |
| **L3 — Agora Builder** | قهوة + مهارة/PR مقبول | شرف المساهمة في Dev Agora + تجربة باقات جديدة قبل الإعلان العام |

Phase 2 العامة تبقى مفتوحة للجميع عبر الريبو؛ الـ **Pass** يضيف شرفاً وأولوية ولطفاً — ليس سوراً يمنع التعلم.
