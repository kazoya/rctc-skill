# نبض الذات (Self-Pulse) — الإصدار المجاني

مهارة لوكلاء الذكاء الاصطناعي لقياس **الحالة التشغيلية**، الثقة قبل التنفيذ، نتائج المهام المُتحقَّق منها، وعزل سجل تفاعلات العملاء.

## تنبيه علمي

- **ليست وعيًا اصطناعيًا.**
- **ليست مشاعرًا حقيقية.**
- درجة «الرضا الوظيفي الحسابي» (`FunctionalSatisfactionScore`) مؤشر تشغيلي شفاف فقط، وليست انفعالًا.

مستوحاة من مختبر Project SELF دون تعديل نتائجه البحثية.

## التثبيت

```bash
cd self-pulse
npm test
node examples/demo-interaction.js
```

## القواعد

1. فصل ما يقوله النموذج عمّا يُتحقق منه خارجيًا.
2. لا اختراع لدرجات رضا العملاء.
3. لا تسريب بيانات بين معرّفات العملاء.
4. لا نشر تلقائي ولا جمع بيانات عملاء حقيقية أثناء التطوير بهذه المهارة وحدها.
