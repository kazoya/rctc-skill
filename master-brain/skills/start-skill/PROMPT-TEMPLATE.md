# قالب البرومبت الجاهز / Ready-to-paste prompt template

انسخ، املأ ما بين ‹›، أرسل. / Copy, fill the ‹› placeholders, send.

## عربي

```text
نفّذ مهارة البدء (/start-skill).

الجلسات/المشاريع: ‹cse_…› (‹اسم المشروع 1›)، ‹cse_…› (‹اسم المشروع 2›)، ‹cse_…› (متفرقات).
مجلد المنصة: ‹E:\master›     مجلد المشاريع: ‹D:\projects›
اللغة: ‹عربي + إنجليزي›     صيغ التقارير: ‹HTML/PDF + Excel + Markdown›
عبّئ العقل الهندسي لكل مشروع مما تعرفه من الجلسات السابقة: ‹نعم/لا›.

القواعد: اقرأ العقل قبل العمل وسجّل بعده؛ انسب كل مقترح إلى النموذج الذي قدّمه؛
اطلب أي أداة ترفع مستوى التنفيذ (n8n، Notion، VM، XAMPP…) عبر request_tool وانتظر موافقتي؛
لا ترفع بياناتي إلى GitHub — الأداة فقط؛ وثّق ما تعلمته ومهاراتك وأدواتك في LEARNED.md وعلى المنصة.

المخرجات: المنصة مثبّتة ومختبرة + zip بورتابل للرفع إلى GitHub + ملخص بما أُنجز وما ينقص وما يحتاج قراري.
```

## English

```text
Run the Start Skill (/start-skill).

Sessions/projects: ‹cse_…› (‹project 1›), ‹cse_…› (‹project 2›), ‹cse_…› (misc).
Platform folder: ‹E:\master›     Projects root: ‹D:\projects›
Language: ‹Arabic + English›     Report formats: ‹HTML/PDF + Excel + Markdown›
Seed each project's engineering mind from what you know of earlier sessions: ‹yes/no›.

Rules: read the brain before working and log after; attribute every suggestion to the model that made it;
request any tool that raises execution quality (n8n, Notion, VM, XAMPP…) via request_tool and wait for my approval;
never push my data to GitHub — only the tool; document what you learned, your skills and tools in LEARNED.md and on the platform.

Deliverables: installed & tested platform + portable zip for GitHub + summary of what is done, what is missing, and what needs my decision.
```

## أمثلة مهام يومية بعد التأسيس / Daily follow-ups after setup

```text
راجع كل المشاريع (daily_review) وأعطني أهم 3 خطوات لكل مشروع نشط، ثم أنشئ تقرير الأسبوع بصيغة all.
ابدأ العمل على ‹project-id› (start_work): المهمة ‹…›. سجّل التقدّم عند الانتهاء.
أضف مقترحاً منسوباً إليك لمشروع ‹project-id›: ‹…›.
ولّد تقرير ‹2026-09-01› → ‹2026-09-30› مجمّعاً حسب الحالة بصيغة Excel وPDF.
```
