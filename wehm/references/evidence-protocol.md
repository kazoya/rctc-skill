## Confidence labels

- **Verified:** reproduced in the authorized environment with preserved evidence.
- **Supported:** primary documentation and code support it; reproduction incomplete.
- **Hypothesis:** plausible but unverified; never report as a confirmed vulnerability.
- **Rejected:** evidence falsified the hypothesis; retain the negative result.
