# 05 — Platform Workflows (high level)

Covers common patterns on **HackerOne**, **YesWeHack**, **Intigriti**, and similar authorized programs.

> **The current official program policy always overrides this training material.**

## Shared workflow (conceptual)
1. Create researcher account / complete verification as required  
2. Read program brief + scope + out-of-scope + rules of engagement  
3. Run **Scope Guard** with your evidence  
4. Prefer local labs until authorization is solid  
5. Submit report via the platform  
6. Respond to triage  
7. Follow disclosure rules  

## Differences (high level — verify live)
| Topic | What often varies |
|---|---|
| Severity scales | Program-defined tables |
| Safe harbor language | Presence and conditions |
| Asset definitions | Wildcards, CIDR, mobile apps |
| Collaborative / invite-only | Access rules |
| Mediation / dispute | Platform-specific |

Do **not** hard-code dollar amounts, banned techniques, or legal claims here — they change.
