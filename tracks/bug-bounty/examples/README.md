# Safe examples

All demos run against **localhost**, **local HTML**, or **synthetic JSON**.  
No third-party production system is required to finish the track.

1. Read `lab/mock-api-access.json` and write an IDOR hypothesis.  
2. Open `lab/reflection-demo.html` locally and reason about output encoding.  
3. Study `synthetic/sample-get.http.json` as evidence formatting practice.  
4. Always pass Scope Guard with a `local_lab` context first.
