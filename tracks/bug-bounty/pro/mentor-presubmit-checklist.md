# Mentor pre-submit checklist (Pro)

Use before sending any report (lab practice or authorized program).

## Authorization
- [ ] Program URL saved + policy read date recorded
- [ ] Asset explicitly listed in scope
- [ ] Activity explicitly permitted
- [ ] Scope Guard decision is `AUTHORIZED_FOR_DECLARED_ACTIVITY` or `USE_LOCAL_LAB`
- [ ] If uncertain → STOP (do not submit speculative live tests)

## Report quality
- [ ] Title names asset + issue class
- [ ] Steps are minimal and deterministic
- [ ] Evidence redacts secrets/PII
- [ ] Impact section states **who can do what to whom**
- [ ] Severity rationale cites program scale (no vibes-based CVSS)
- [ ] Observation vs demonstrated impact distinguished
- [ ] Remediation is defensive and practical
- [ ] No threat of public disclosure

## Honesty
- [ ] No claim of testing platforms/programs without real authorized evidence
- [ ] Lab-only findings labeled as lab
