# 00 — الأخلاقيات والتفويض والنطاق

**المسار:** تدريب Bug Bounty الأخلاقي (تعليم دفاعي)  
**الجمهور:** متعلمون يمارسون بحث الثغرات بمسؤولية

## الغرض
تعليم متى يُسمح بالاختبار الأمني، وكيف تُقرأ سياسة النطاق، ومتى يجب **التوقف**.

## قاعدة صريحة
> الإذن خاص بأصل محدد وفعل محدد. الموقع العام ليس تلقائياً مصرّحاً لاختبار أمني.

## قائمة تفويض قبل أي نشاط يتجاوز قراءة الوثائق العامة
1. **من يملك الأصل؟** (أنت / جهة عملك بتفويض مكتوب / برنامج مكافآت منشور)
2. **أي أصل؟** (نطاق أو تطبيق أو API كما هو مدرج)
3. **أي أفعال؟** (قراءة سلبية مقابل اختبار مصادق مقابل فحوصات أعمق)
4. **ما الدليل؟** (رابط البرنامج + نص السياسة، خطاب تكليف، ملكية المختبر)
5. **ما المحظور؟** (حدود المعدل، فئات مستثناة، أصول خارج النطاق)

أي غموض → **توقّف** واستخدم **مختبراً محلياً / ديمو**.

## داخل النطاق مقابل خارجه
| المفهوم | المعنى |
|---|---|
| داخل النطاق | أصول/أفعال مصرّح بها صراحة |
| خارج النطاق | استثناءات مدرجة أو أي شيء غير مشمول بوضوح |
| رمادي | يُعامل كـ **خارج النطاق** حتى يوضح البرنامج |

## فئات محظورة في هذا المسار
الثبات (persistence)، سرقة بيانات الدخول، التصيد، البرمجيات الخبيثة، التدمير، التخفي/التملص، إساءة الصلاحيات، حجب الخدمة، الاستغلال الجماعي، الاختبار خارج النطاق، تجاوز قيود البرنامج، إخفاء النشاط عن المدافعين.

## حدود المعدل والتعامل الآمن مع البيانات
- احترم حدود المعدل والاستخدام العادل.
- لا تحتفظ ببيانات شخصية أكثر مما يلزم للتقرير.
- احجب الأسرار وPII في الملاحظات واللقطات.
- خزّن الأدلة محلياً بتحكم وصول؛ لا تلصق أسراراً في محادثات عامة.

## الإفصاح المسؤول
- بلّغ عبر القناة الرسمية للبرنامج.
- لا تفصح علناً قبل أن تسمح القواعد.
- لا تطالب بدفع خارج شروط البرنامج.
- للحوادث الحرجة: اتبع مسار الطوارئ في سياسة البرنامج.

## متى تتوقف فوراً
- الأصل غير واضح في النطاق
- النشاط غير مصرّح بوضوح
- ظهور PII لعملاء أحياء لا يجب الاحتفاظ بها
- طلب البرنامج التوقف
- الشك → `USE_LOCAL_LAB`

## بيئات مسموحة في هذه الدورة
1. مختبرات محلية تملكها  
2. تطبيقات تدريب هشّة عمداً  
3. أهداف CTF/ديمو تعليمية  
4. برامج Bug Bounty الرسمية **فقط** عندما يكون الأصل داخل النطاق والقواعد تسمح بالاختبار  

## برومبت RCTC (مذكرة تفويض)
- **الدور:** متعلم أمن يتبع الإفصاح المسؤول  
- **السياق:** اسم البرنامج + الرابط + مقتطف قائمة الأصول  
- **المهمة:** قرار AUTHORIZED / INSUFFICIENT / OUT_OF_SCOPE / USE_LOCAL_LAB  
- **القيود:** الرفض الافتراضي؛ لا تفويض تقريبي؛ استشهد بالدليل  

ثم شغّل `bug-bounty-scope-guard` بهذه المذكرة.
