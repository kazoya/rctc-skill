**Original concept, workflow design, and authorship:** **Suhaib Asrawi** (GitHub: [@kazoya](https://github.com/kazoya)).

Start Skill was conceived to turn scattered AI conversations, work sessions, and side projects into one evidence-driven portfolio: one governed workspace per project, a persistent engineering brain, model-attributed suggestions, progress reports, and operational bridges to coding agents.

The public repository record dates this authorship through Git commits and releases. For formal citation, see [CITATION.cff](CITATION.cff).

## Authorship versus implementation assistance

The originating problem definition, product direction, orchestration model, and acceptance philosophy are attributed to Suhaib Asrawi. AI systems and development tools may assist with research, code generation, testing, review, and documentation. Such assistance does not replace the named human author or imply that every generated contribution was written manually.

Material third-party code or ideas must retain their original licenses and attribution. Contributors remain credited through Git history and pull requests.

## Intended professional use

Start Skill is designed as an orchestration and evidence framework for complex, high-fidelity work, including multi-application platforms, AI systems, regulated workflows, research portals, and long-running product portfolios. It emphasizes:

- traceability from request to decision, implementation, verification, and evidence;
- explicit project states, ownership, priorities, constraints, and blockers;
- model-attributed suggestions and human approval boundaries;
- privacy-aware separation between reusable tooling and local project data;
- staged delivery with testable acceptance criteria.

It is not a certification, warranty, patent registration, or substitute for domain review in legal, medical, financial, safety-critical, or regulated projects.
