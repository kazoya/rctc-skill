# Prize-hunt skill fit — اصطياد الجوائز حسب المهارة المُثبتة

تختار النافذة التي تطابق صنفاً أُنجز وقِيس. الجائزة الكبيرة ليست سبباً للدخول.

```text
LEDGER → CLASS → FIT → GATE → ONE WINDOW
```

## القاعدة

`ملاءمة الصنف × واقعية الجائزة ÷ الساعات حتى تسليم صالح`

- صنف بلا قياس محلي = لا دخول.
- رقم لوحة بلا تاريخ ومصدر = ليس نتيجة.
- مهارة أمنية هنا تعني حكماً وتفويضاً وأدلة، لا خطوات استغلال.

## الأصناف المُثبتة

| الصنف | دليل عام | ماذا يعني للقرار |
|---|---|---|
| اختلاف تحليل بين طبقتين | Dojo عام مُسلَّم، وتحدٍّ شهري قُبل بشدة متوسطة ومكافأة صفر | النافذة التالية من نفس الصنف أولاً |
| تصنيف جدولي بتعزيز التدرج | حلقتا ملعب مغلقتان بنتائج عامة مؤرخة، بلا ميدالية نقدية | تمرين أو بضاعة، لا مسار نقد |
| محاكاة وكيل | مسابقة مزرعة أُغلقت بلا ميدالية | لا تُعاد إلا إذا عاد نفس نوع اللوحة وبزمن كافٍ |
| أمن وكلاء متعدد الخطوات | مشاركة أُغلقت بنتيجة محفوظة بلا مركز معلن | لا تُروى كفوز |
| شبكات مكانية | درجة عامة صفر على مسار الشبكة، وأرقام منخفضة على المسار الآخر | لا تُقدَّم كقوة |

التفاصيل والأرقام في [EVIDENCE.md](EVIDENCE.md). لا تنسخ أعلاماً ولا حمولات إلى أي ملف عام.

## أصناف لا تُقاد بها

تتبع رياضي، رؤية متخصصة، ضبط نماذج كبير بلا عتاد مُقاس، هندسة عكسية ثنائية، تحقيق جنائي، رشّ برامج مكافآت.

## سير العمل

1. اقرأ دفتر الأدلة. افصل ما قِيس عما بقي استنتاجاً.
2. سمِّ صنف النافذة المرشحة في جملة: تحليل، جدول، محاكاة، وكيل، رؤية، مجال آخر.
3. اقبلها فقط إذا طابقت صنفاً مثبتاً، والمهلة تسمح بتسليم واحد صالح، والجائزة ليست يانصيب وقت قصير.
4. إن كانت النافذة أمنية: مرّ عبر WEHM وحارس النطاق. غموض التفويض = توقف. مختبر أو تحدٍّ بقواعده، أو أصل داخل سياسة برنامج حالية. لا اختبار حي من هذه المهارة.
5. نافذة واحدة. لا رشّ.
6. انشر الطريقة والدرس. لا تنشر سراً ولا علماً ولا حمولة ولا Finding غير مفصح.

## ممنوع

- أسرار، مفاتيح، جلسات، أعلام، حمولات، أسماء حسابات خاصة.
- ادعاء مركز أو ميدالية بلا `publicScore` حي ومؤرخ.
- تعليم استغلال أو تجاوز تحقق أو حدود معدل.
- فتح مسار المكافآت المجمد لإضافة دروس.
