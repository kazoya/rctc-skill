# Dogfooding record — the suite decided a prize, then kept the lesson

Composition law:

> Reuse → Compose → Extend → Generate New

## Pass A — existing skills shaped this one

On 2026-10-08 the question was whether to enter the NFL Big Data Bowl ($100,000, deadline 6 January 2027).

Three candidates:

1. Enter the sports-tracking analytics contest because the prize is large.
2. Enter a model-training agent contest with no measured local training result.
3. Keep the next window inside a class already solved: two-layer parsing, plus tabular playground only as practice.

The comparison used skills already in this repository:

- **RCTC** bounded the decision: role is a prize operator, context is the measured ledger, task is go or no-go, constraint is no secrets and no exploit text.
- **evidence-before-claim** rejected peak scores and unreadiness as proof.
- **HTPAAP** required the chain `source → claim → evidence → lesson → pattern` before any public sentence.
- **WEHM** kept security experience at authorization, class, and disclosure. The frozen bug-bounty track was not reopened.
- **Focus Council's rule** (compare, then one recommendation) selected candidate 3.

This folder is that pattern, not a new exploit track.

## Pass B — the prize lesson went back into evidence-before-claim

A competition score is a claim. The ledger now requires a dated public score, and it forbids treating a mid-contest peak as a final rank. That sentence was written back into `evidence-before-claim` so the next prize decision does not relearn it.
