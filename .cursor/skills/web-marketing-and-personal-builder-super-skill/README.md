## What it is

A **production OS** (not a one-shot prompt) that:

1. Accepts a **URL**, a **short bio**, or a **company blurb**
2. Inspects public facts honestly
3. Builds an Arabic/RTL (or bilingual) marketing / digital-concept site
4. Adds WhatsApp QR, human-in-the-loop automation ideas, and one interactive engine
5. Proves with `build` + smoke
6. Ships **GitHub + Vercel**

Sibling specialists stay available: `factory-sales-concept`, `ui-ux-pro-max`, `focused3-agentic-phases`, `projects-connector`.

## Why it feels “hands-off”

| Piece | Effect |
|-------|--------|
| Intake table + RCTC | One question, not an interrogation |
| safe-forward-execution / focused3 | Prove before forward; no fake done |
| ui-ux-pro-max (optional) | Design craft without reinventing taste |
| Git-linked Vercel | Push → READY automatically |
| Multi-agent optional | Research ∥ design ∥ build ∥ verify |
| Local Ollama optional | Private draft copy — never deploy authority |
