# Examples

## 1) Muqasa-Jo style (marketplace marketing)

**Input:** auction / clearing product story + brand assets  
**Output:** Arabic concept site explaining the product journey, trust, and CTA — **not** the live auction engine in `C:\muqasa`.  
**Live craft target users cite:** [muqasa-jo.com](https://muqasa-jo.com)  
**Lesson:** marketing shell can look production-grade while core product stays elsewhere.

## 2) Banoon Kids (factory / retail)

**Input:** `https://www.banoonkids.com` + WhatsApp + differentiator (schools contest, no preservatives)  
**Path:** `C:\Factories\Banoon`  
**Engine:** contest / prize with human approval  
**Lesson:** URL + differentiator is enough; parent company from About.

## 3) Al-Majjarra (field / irrigation)

**Input:** fertilizer / irrigation public site  
**Engine:** irrigation suggestion — valve stays human  
**Lesson:** automation opportunities must be realistic (WhatsApp order book ≠ MQTT plant).

## 4) Virtual Strata (B2B executive reposition)

**Input:** ICT company URL + recipient name  
**Tone:** calm proposal, not “hire me or buy”  
**Engine:** tender board with human approval  
**Lesson:** same stack; positioning flip is a first-class mode of this super-skill.

## 5) Personal consultant

**Input:** name, WhatsApp, one offer sentence  
**Pages:** home, offer, selected work, contact + QR  
**Lesson:** do not invent employers or clients; use “selected work” only with permission.
