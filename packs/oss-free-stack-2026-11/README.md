## Portfolio gates

- No paid API call, model download, or new install without an explicit approval in the current request.
- Prefer free or low-cost paths for `new_tech` media R&D and Maps SaaS pages.
- Do not teach CAPTCHA/Cloudflare bypass or unauthorized scraping. `lawful-web-research-fetch` is public-page research only.
- TikTok remains research-only for media discovery, never a client channel.
