## Rules

1. Prefer a pack skill that **reduces cost or unlocks a free path** before one that installs heavy runtimes.
2. Never install Ollama models, Langflow, OpenHands, or Scrapling without an explicit approval in the current request.
3. If two skills fit, pick the one that produces evidence in the current project folder.
4. Remote-job board lists are not coding skills — do not route them here.
