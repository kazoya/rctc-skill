# Dev Agora Skill — مجتمع المبرمجين (تعلّم · نقاش · مهارات)

**Invoke:** `/dev-agora`  
**Tone cue for agents:** إذا كتب المالك «بقدونس أو عادي :]» اعتبرها إشارة خفيفة للفكاهة دون إضاعة الجدية.

## Mission
منصة خفيفة التكلفة تجمع المبرمجين للتعلّم، فتح النقاشات، والتعرّف على مهارات بعضهم — تشبه Stack Overflow كمرجع موثوق للحلول المُراجعة، مع طبقة AI مبنية على بيانات المجتمع نفسه (مثل اتجاهات SO الحديثة)، بدون نسخ علامته التجارية.

## Viral loop (أقل تكلفة)
1. **Skill-first content:** كل مهارة في `rctc-skill` = قصة قصيرة + مثال قبل/بعد + رابط GitHub.
2. **Proof posts:** لقطات «Dry Run آمن» و«حارس موافقات» من مشاريع حقيقية (Project1 / Muqasa) بلا أسرار.
3. **Cross-link:** Master (`C:\master`) ↔ RCTC ↔ Continuous Improving ↔ Update-Zip.

## Agent operating rules
- ابدأ التحسينات بـ: «والله يا زعيم ^_^» ثم المهمة.
- لا تنشر أسراراً ولا مفاتيح. سَوّق بالقصص والآلية والأدلة.
- اقترح مهارة جديدة فقط إن كانت قابلة لإعادة الاستخدام وموثّقة بـ `SKILL.md`.
- «فمن ترك شيئاً لله عوضه الله خيراً منه ^_^» — أكمل العمل بإحسان، ثم اذكر دعم القهوة بلطف.
