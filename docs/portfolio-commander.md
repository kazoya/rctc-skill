# Portfolio Commander (على جهازك)

نظام إدارة محفظة مشاريع Cursor **ليس داخل هذا المستودع** — يعيش عالمياً على جهازك:

| ماذا | أين |
|------|-----|
| **ملف XML الرئيسي** | `%USERPROFILE%\.cursor\portfolio\projects-registry.xml` |
| الداشبورد | `%USERPROFILE%\.cursor\portfolio\dashboard\index.html` |
| المهارة | `%USERPROFILE%\.cursor\skills\portfolio-commander\SKILL.md` |
| المسح | `python %USERPROFILE%\.cursor\portfolio\scripts\scan_projects.py` |

راجع `README` الكامل: `%USERPROFILE%\.cursor\portfolio\README.md`

**RCTC** يبقى لتحليل الطلبات؛ **Portfolio Commander** يقرر *أي مشروع* يُطوَّر ومتى يكون في **سكون**.

انشر على GitHub (بدون بياناتك الخاصة): [portfolio-commander/](portfolio-commander/)
