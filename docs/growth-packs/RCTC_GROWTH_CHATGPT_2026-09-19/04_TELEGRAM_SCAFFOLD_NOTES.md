# Telegram bot — scaffold now, go live later

Recommended minimal bot (Telegraf or grammY):

Commands:
- /start — welcome + link to repo + beginner-coding-path one-liner
- /packages — list package ids from catalog
- /cert — link to latest Agora certificate
- /support — optional coffee + PayPal (only here)
- /prompt — paste FIRST_PROMPT short version

Do **not** hardcode secrets. Owner sets TELEGRAM_BOT_TOKEN locally.

A starter folder may be added under `channels/telegram-rctc-bot/` in-repo as non-secret scaffold.
