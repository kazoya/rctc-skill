### Phase 2 north star
1. Discover and compose skills  
2. Generate new skills safely (**Skill Factory**: draft → validate → review → package → repo-ready → publish*)  
3. Export a skill as a clean standalone GitHub repo  
4. Validate / test / document  
5. Make outside contribution easy  
6. Grow a **Dev Agora** layer (Stack Overflow–inspired mechanics, GitHub-native first — Discussions + issue forms — not a clone of SO)

\* Publish stays an **owner gate**. No auto-push vanity.

### Ethical growth loop (not spam)
`Useful skill → reproducible demo → GitHub repo → discoverable docs → contribution path → community recipe → reusable skill → release`

We will **not** fake stars, votes, testimonials, bot accounts, or popularity metrics.
