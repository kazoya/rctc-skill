## Positioning for complex, high-fidelity projects

Start Skill is positioned as the governance layer around demanding projects, rather than as a promise that an AI agent can complete every project autonomously. For high-fidelity delivery, it adds five controls:

1. **Project truth:** one canonical status for work completed, findings, current work, next work, decisions, constraints, and blockers.
2. **Requirements traceability:** requirements and acceptance criteria connect to implementation, tests, verification, and evidence.
3. **Controlled autonomy:** tools and models can propose or execute within explicit permissions; material decisions remain attributable and reviewable.
4. **Quality gates:** no “done” state without implementation, tests, verification, and retained evidence.
5. **Portfolio continuity:** long-running projects survive chat boundaries, model changes, pauses, and handoffs.

## Suitable project classes

- Multi-application SaaS and enterprise platforms
- AI agents and human-in-the-loop automation
- Research and evidence portals
- Multilingual and accessibility-sensitive products
- Hardware/software integrations
- Regulated or safety-sensitive systems with appropriate domain experts
- Multi-team or multi-model programs requiring auditable handoffs

## Evidence package expected from a high-fidelity engagement

| Layer | Minimum retained evidence |
|---|---|
| Intent | owner request, assumptions, constraints, acceptance criteria |
| Architecture | decisions, alternatives, interfaces, data boundaries |
| Delivery | implementation commits and attributable work log |
| Quality | tests, security/privacy checks, accessibility and performance results |
| Verification | reproducible commands, outputs, screenshots or reports |
| Governance | approvals, blockers, risks, exceptions and release decision |
