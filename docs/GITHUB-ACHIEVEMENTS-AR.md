# GitHub Achievements — آلية الزيادة (kazoya)

الشارات في الملف الشخصي **ليست ديكوراً ثابتاً**: لها عدّادات ومستويات. ظهور التحديث غالباً خلال **24–48 ساعة**.

## الشارات الظاهرة عندك الآن

| الشارة | الشرط الأساسي | كيف نزيدها |
|--------|----------------|------------|
| **Quickdraw** | إغلاق Issue أو PR خلال دقائق من فتحه | عادة شارة واحدة؛ كرّر السلوك في Issues حقيقية قصيرة العمر |
| **Pull Shark** | دمج Pull Requests | **2 → 16 → 128 → 1024** دمجات (المستوى التالي هدفنا العملي: 16) |
| **Pair Extraordinaire** | PR مدموج فيه commit بـ `Co-authored-by:` لحساب GitHub حقيقي | **1 → 10 → 24 → 48**؛ يحتاج شريك/حساب ثاني مرتبط بالإيميل |
| **YOLO** | دمج PR بدون مراجعة | عادة شارة واحدة؛ تتحقق تلقائياً عند الدمج الذاتي بدون review |

## ما نفعله في هذا المستودع (مشروع لا سبام)

1. PR حقيقي للتنظيف والمزامنة → يزيد **Pull Shark** (+YOLO إن دُمج بدون مراجعة).
2. Issue يتتبع هدف «Pull Shark Bronze (16)» ويُغلق عند اكتمال شريحة عمل → يدعم **Quickdraw** إن أُغلق سريعاً.
3. **Pair Extraordinaire**: لا نزوّر Co-author؛ عند العمل مع مساهم حقيقي نضيف:

```text
Co-authored-by: Name <noreply@github-user-id.users.noreply.github.com>
```

## سياسة نظافة المهارات

- المصدر الكانوني: مجلد المهارة في جذر المستودع أو `tracks/`.
- `.cursor/skills/` و`.agents/skills/` و`skill-factory/out/` و`dist/` = مرايا/مخرجات **غير متتبَّعة**.
- ثبّت المرايا محلياً عبر سكربتات التثبيت عند الحاجة.
