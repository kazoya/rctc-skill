# 60-second quickstart — RCTC / Digital Presence Factory

1. Clone: `git clone https://github.com/kazoya/rctc-skill.git && cd rctc-skill`
2. List recipes: `node digital-presence-factory/cli.js --list`
3. Plan (no deploy):  
   `node digital-presence-factory/cli.js --type technical-delivery --source path\to\your\portfolio`
4. Read the plan: reused skills, gaps, owner gates, verify commands.
5. Star the repo if it saved you time — then open a Discussion or issue with your compatibility notes.

**One-command demo (plan only):**
```bash
node digital-presence-factory/cli.js --type personal --source .
```

Publish/deploy is **never** implied by a green plan.
