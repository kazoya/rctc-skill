# Skill contribution guide

## Preference order
**Reuse → Compose → Extend → Generate New**

## Good first skill
- Thin orchestrator or recipe JSON that composes ≥2 existing registry skills
- Clear `verify` commands
- No secrets, no auto-publish, no invented metrics
- Includes honesty notes (demo vs production)

## Good first issue
- Compatibility report (OS, Node, Cursor/Claude/Codex version)
- Broken link / unclear quickstart step
- Recipe gap with a reproducible folder or URL
- Typo / docs clarity

## Discussions structure (recommended)
| Category | Use for |
|---|---|
| Announcements | Releases only (maintainers) |
| Ideas / RFCs | Phase proposals, recipe designs |
| Q&A | Reproducible questions (→ community-to-skill flywheel) |
| Show and tell | Demos, compatibility wins |
| Skill recipes | Compose chains that worked |

GitHub is source of truth. Telegram/Discord may discover, not canonize.
