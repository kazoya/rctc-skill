# منظومة مهارات صهيب — From idea to verified delivery

> مجموعة مهارات مترابطة تنقل العمل من طلبٍ مبهم إلى مشروع منظم، ثم إلى تنفيذ واختبار وتسليم موثّق.

هذه المهارات ليست أسماءً مختلفة للشيء نفسه. لكل واحدة مهمة مستقلة، ويمكن تركيبها معاً حسب المشروع.

## هل تعلم؟

> **هل تعلم أنك من خلال [Web Marketing & Personal Builder](../web_marketing_and_personal-builder-super-skill/) وقليل من الإعدادات تستطيع إنشاء موقع بمستوى حرفي قريب من [muqasa-jo.com](https://muqasa-jo.com)، مع أقل قدر ممكن من التدخل—خصوصاً عندما تستخدم معها [Safe Forward Execution](../safe-forward-execution/)؟**

المقصود ليس وعداً سحرياً أو ضماناً لنتيجة تجارية؛ بل مسار هندسي يقلل الأسئلة غير الضرورية، يحافظ على حدود الصلاحية، وينقل المشروع من الفكرة إلى بناء واختبار ودليل.

## 1. Web Marketing & Personal Builder — Super Skill

**من رابط واحد أو نبذة قصيرة إلى منصة عرض احترافية.**

مناسبة للمصانع، الشركات، المنتجات، الخدمات، الاستشاريين، المحامين، العلامات الشخصية، والنماذج الأولية لمنصات SaaS. تبدأ من الحقائق المتاحة، تبني تجربة عربية RTL أو ثنائية اللغة، تضيف CTA وWhatsApp وأفكار أتمتة مناسبة، ثم تختبر وتجهز GitHub وVercel ضمن الصلاحيات المتاحة.

**أفضل تركيبة:**

```text
web-marketing-and-personal-builder
+ safe-forward-execution
+ focused3-agentic-phases
= INSPECT → DESIGN → BUILD → VERIFY → SHIP
```

[افتح المهارة](../web_marketing_and_personal-builder-super-skill/)

## 2. Safe Forward Execution

**الخطة محطة، وليست نهاية المهمة.**

تمنع الوكيل من تسليم Roadmap ثم التوقف، وتجعله يواصل إلى أكبر نتيجة متماسكة يمكن إنجازها بأمان داخل النطاق: تعديل، اختبار، بناء، تحقق، ثم تقرير صادق. لا تمنحه تفويضاً مفتوحاً؛ النشر، الدفع، القرارات الجوهرية، والعمليات الخطرة تبقى عند بوابات بشرية واضحة.

[افتح المهارة](../safe-forward-execution/)

## 3. Factory Sales Concept

**حوّل موقع المصنع من بروشور ساكن إلى تصور مبيعات وتشغيل.**

تستخرج الكتالوج والحقائق المنشورة، تعرض فرص CRM والطلبات والعروض والأتمتة وROI التوضيحي، وتبني CTA عملياً ومساراً تفاعلياً مناسباً للعمل، مع إبقاء السعر والادعاءات والقرارات الحساسة تحت اعتماد بشري.

[افتح المهارة](../factory-sales-concept/)

## 4. Start Skill

**من عشر محادثات وعشرة مشاريع إلى عقل هندسي واحد.**

تنشئ خانة ومجلداً لكل مشروع، وتحفظ ما تم، والنتائج، والجاري، والتالي، والقرارات، والعوائق، والمقترحات المنسوبة إلى أصحابها. مناسبة لمن يملك أفكاراً كثيرة ويحتاج أن يعرف أين يقف كل مشروع دون إعادة قراءة التاريخ كله.

[افتح المهارة](../start-skill/)

## 5. Portfolio Commander

**اعرف ماذا تعمل الآن، وماذا تؤجل، ولماذا.**

سجل موحد للمشاريع والأولوية والتقدم والعائد والحالة، مع قواعد للسكون تمنع إهدار الوقت على مشروع متوقف أو غير مصرح بتطويره.

[افتح المهارة](../portfolio-commander/)

## 6. Master Brain

**طبقة تشغيل حقيقية للمحفظة، لا ملف Markdown يتيم.**

منصة Node.js مرجعية تضم Dashboard وCLI وMCP وتقارير وذاكرة هندسية للمشاريع، لتصبح Start Skill وPortfolio Commander قابلتين للاستخدام والمتابعة.

[افتح المنصة](../master-brain/)

## 7. Focused3 Agentic Phases

**فكّر، نفّذ، ثم أثبت.**

تفصل العمل إلى THINK → EXECUTE → PROVE وتستخدم بوابات جودة وأدلة، حتى لا يصبح «تم» مرادفاً لـ«كتبت بعض الملفات».

[افتح المهارة](../focused3-agentic-phases/)

## 8. Continuous Improving

**حلقة تحسين مستمر لا تتوقف عند أول نتيجة—ضمن نطاق مصرح به.**

مناسبة للتجارب الهندسية، SaaS، المسابقات والأبحاث الأمنية المصرح بها. تقيس، تحلل، تعدل، تختبر وتكرر، لكنها تتوقف عند المال، الحسابات، الإنتاج، البيانات الحساسة، الحدود القانونية، أو أي قرار بشري حقيقي.

[افتح المهارة](../continuous-improving/)

## 9. Update-Zip Skill

**من مشروع مبعثر إلى حزمة أدلة قابلة للاستشارة والمراجعة.**

تحصد الحقائق والاختبارات والقيود، وتبني ZIP منظماً لوكيل خارجي، ثم تعيد الحزمة الناتجة إلى مسار مراجعة مضبوط. لا تكتب في المشروع أو قاعدة البيانات تلقائياً؛ التطبيق الحي يحتاج بوابة صريحة.

[افتح المهارة](../update-zip-skill/)

## 10. RCTC Method

**Role → Context → Task → Constraints**

بوابة الوضوح قبل التنفيذ: تسأل السؤال الوحيد الذي يغيّر النتيجة فعلاً، وتستنتج التفاصيل الصغيرة المعقولة بدلاً من تحويل كل طلب إلى استجواب.

[افتح RCTC](../SKILL.md)

     → Focused3 Agentic Phases

            → Safe Forward Execution per active project

```text

                     → Safe Forward Execution → Focused3 proof gates
```

## معيار الصدق

هذه المنظومة تساعد على رفع جودة التنفيذ وتقليل التدخل، لكنها لا تعد بموقع ناجح تجارياً بلا محتوى حقيقي، ولا تنشر أو تدفع أو تتصرف باسم المستخدم دون صلاحية. كل ادعاء اكتمال يجب أن يسنده تنفيذ واختبار وتحقق ودليل.
