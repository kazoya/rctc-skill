# Public developer experiment (ONE challenge — not a campaign)

## Title
**Give RCTC one developer problem.**

## What a developer does
1. Open https://github.com/kazoya/rctc-skill
2. File a Discussion or Issue with:
   - one real, small problem
   - one reproduction path (folder, URL, or 5–10 line steps)
3. Watch the public proof path:
   **Problem → discovery → existing skill search → composition → execution/solution → evidence → reusable recipe candidate**

## What RCTC demonstrates
- Prefer Reuse → Compose → Extend → Generate New
- Exact registry ids (STOP/GAP on unknowns)
- Execution ledger as evidence
- No auto-publish of new skills

## CTA
> Give RCTC one real developer problem. If it saves you time, Star the repository so another developer can find it. If you cannot sponsor the project, contribute a question, verified answer, compatibility result, example, recipe, skill, or share.

Coffee/sponsorship optional only with approved URL (see `docs/SUPPORT_BLOCK.md`).

No fake stars, users, votes, testimonials, or spam.

## Package
When a run is safe to share: publish before/after + ledger excerpt (secrets stripped).
